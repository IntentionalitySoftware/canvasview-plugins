# CanvasView for Claude Code

1. Run `/plugin marketplace add IntentionalitySoftware/canvasview-plugins` in Claude Code.
2. Run `/plugin install canvasview@canvasview`.
3. Run `/reload-plugins` if Claude Code prompts you to reload.
4. Open `/mcp` and select CanvasView.
5. Sign in to CanvasView and approve access in your browser.

See [CanvasView documentation](https://docs.canvasview.dev/) for account setup and a test prompt.
